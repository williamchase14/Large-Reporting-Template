# Large Reporting Template
This repository contains the code, data, and assets used to generate 35 + data visualizations. The final deliverable is a PowerPoint presentation composed of approximately 33 charts and tables, summarizing key insights from survey responses and related reference data.

## Project Overview

Input data are collected and exported as CSV files.
Python scripts are used to merge, clean, and enrich the raw exports into a single analytic data file.
R scripts generate formatted charts and summary tables from the merged dataset.
Chart outputs are saved as PNG files or manually assembled into a PowerPoint presentation.

## Current Workflow

### Data Collection
Data is stored as CSV files and placed in Survey Data/All CSVs/.


### Data Preparation (Python)
Python scripts in the Survey Data/ folder are run sequentially to:
- Merge survey CSV files,
- Join IPEDS, MSI, and Carnegie reference data,
- Produce the final analytic dataset:
- 00 Source data file.xlsx.


### Chart and Table Generation (R)
R scripts in Summary Report - R Charts/Master/ read the source data file and generate:
- Formatted charts and tables,
- PNG output files saved in the same folder.


### Report Assembly
The exported PNG files are manually compiled into a PowerPoint presentation to produce the final quarterly report.


## Notes
- Archived R scripts are retained in 00. Archive/ for historical reference and are not part of the active workflow.
- The file 00 Source data file.xlsx serves as the single source of truth for all downstream R analyses.
- Output files (PNG charts and PowerPoint decks) are generated artifacts and are not intended for manual editing outside the reporting process.
